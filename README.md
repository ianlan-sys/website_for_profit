# 一签 · YI QIAN

A Chinese-first reflection ritual: choose a concern, draw a card, receive an encouraging reading, and take a small practical action.

- Buildless HTML, CSS and JavaScript in `dist/`.
- 16 authored readings across relationships, work, uncertainty and personal growth.
- Random local selection; no live AI calls, analytics, accounts or personal-data submission.
- Favorites and action intentions stored only in the current browser's localStorage after explicit save.
- Keyboard controls, reduced-motion support and responsive layouts.

Run `node preview.mjs` from this directory to preview at http://127.0.0.1:4173.
Run `node --check dist/app.js` for a syntax check.

Deployment identity is in `.openai/hosting.json`. Use the Sites workflow to publish updates. Site access starts private.
